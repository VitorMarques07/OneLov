# 📌・informações — OneLov

## ONELOV
### CONTROLE DE FARM

👋 **BEM-VINDO AO CONTROLE DE FARM!**

🤖 Este é um sistema automatizado para facilitar o controle e o registro das atividades de farm.

---

## 📦 COMO REGISTRAR UMA ENTREGA

1. Realize sua farm.
2. Clique em **📦 Fazer Entrega**.
3. Preencha as informações solicitadas.
4. Confira os dados.
5. Envie o registro e aguarde a aprovação.

---

## ⚠️ REGRAS IMPORTANTES

- Registre somente suas próprias entregas.
- Confira os dados antes de enviar.
- Não registre informações falsas.
- Não duplique uma entrega.
- Confira a quantidade antes de confirmar.
- Em caso de erro no registro, procure um responsável.
